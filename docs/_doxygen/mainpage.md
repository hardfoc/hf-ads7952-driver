# ADS7952 Driver API reference {#mainpage}

The classes, members and constants of the HardFOC ADS7952 driver, generated from the headers.

Start with ads7952::ADS7952, the driver, and ads7952::SpiInterface, the interface your platform port implements.
Results are ads7952::ReadResult and ads7952::ChannelReadings; compile-time defaults are in the ADS7952_CFG
namespace and the command-word layout in ads7952::reg.

The guides, with examples that compile, are on the documentation site: <a href="../">ADS7952 Driver
documentation</a>.
