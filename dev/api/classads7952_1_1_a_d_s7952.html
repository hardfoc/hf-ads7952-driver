Detailed Description

template<typename SpiType>
class ads7952::ADS7952< SpiType >

Main driver class for the ADS7952 ADC.

Provides a synchronous, command-oriented API over the ADS7952 SPI protocol. The class is transport-agnostic and relies on a CRTP SPI implementation.

Bus errors: when the port's transfer() returns false, the call that sent the frame stops there; bool functions return false and the reads return Error::SpiError. Driver state (mode, masks) is only updated after the frames that change it were transferred.
